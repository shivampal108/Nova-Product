# Product Hub

Product Hub is a backend application developed using **Spring Boot** for managing products, users, authentication, authorization, and product-related operations through REST APIs.

The project follows a layered architecture using Controller, Service, Repository, Entity, and DTO layers.

## 🚀 Features

- User registration and login
- Session-based authentication
- Role-based authorization
- Admin and User roles
- Product management
- Add, update, delete, and fetch products
- Pagination for product listing
- DTO-based request and response handling
- Input validation using Jakarta Validation
- Global API response structure
- Exception handling
- Database integration using Spring Data JPA
- Swagger/OpenAPI API documentation
- Password encryption using BCrypt
- Role-based access control for protected APIs
